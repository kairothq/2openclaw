## Design System & Visual Style

### Color Palette (shadcn-ui dark theme)

**Background:**
- Primary: Black (#000000) or very dark gray (#0a0a0a)
- Cards: Dark gray (#1a1a1a)
- Borders: Subtle gray (#404040 or #262626)

**Brand/Accent:**
- Primary Orange (lobster): #f97316
- Orange hover: #fb923c
- Orange active: #ea580c

**Text:**
- Primary: White (#ffffff)
- Secondary: Light gray (#a1a1aa or zinc-400)
- Muted: Medium gray (#71717a or zinc-500)

**Status Colors:**
- Success/Green: #22c55e
- Warning/Yellow: #eab308
- Error/Red: #ef4444
- Info/Blue: #3b82f6

### Typography

**Font Stack:**
- Primary: System font or Inter/Geist Sans
- Monospace: Geist Mono (for code/API keys)
- Display: Can use custom font for headlines if desired

**Text Sizes:**
- Hero headline: 4xl to 7xl (very large)
- Section headings: 3xl to 4xl
- Subheadings: xl to 2xl
- Body text: base (16px)
- Small text: sm to xs

### Icon Style

**All icons:** Minimalist, line-based (lucide-react style)
- Stroke width: 2px
- No fills, outline only
- Consistent sizing (16px, 20px, 24px)

**Platform Icons:**
- Telegram: Official Telegram icon
- WhatsApp: Official WhatsApp icon
- Keep brand colors for platforms

### Button Styles

**Primary CTA (with shimmer effect):**
- Background: Solid white or orange
- Text: Black or white
- Border radius: Full rounded (pill shape)
- Padding: Generous (px-8 py-4)
- Shimmer/flash animation from template

**Secondary/Outline:**
- Background: Transparent
- Border: 1px solid gray
- Text: White/gray
- Hover: Slight background fill

### Card Styles

**Standard Card:**
- Background: #1a1a1a or similar dark
- Border: 1px solid #404040
- Border radius: 16px to 24px
- Padding: 24px to 32px
- Hover: Subtle border color shift

**Pricing Card (highlighted):**
- Badge: "Popular" in top right
- Border: 2px solid orange (#f97316)
- Slight glow/shadow effect

### Animation Principles

**Framer Motion:**
- Use `whileInView` for scroll-triggered animations
- Fade in + slide up pattern (y: 20 → 0)
- Stagger children by 0.1s
- Smooth easing (ease-out)

**Shimmer/Flash Button:**
- Continuous subtle animation
- Gradient sweep effect
- Or liquid metal border (from template)

**3D Globe:**
- Rotating slowly
- Pulsing dots for user locations
- Smooth 60fps animation

## Notes on Tone & Style

**Do:**
- Use "you" and "your" (conversational)
- Be simple and direct like SimpleClaw
- Use specific numbers (80 users, 12 countries)
- Show, don't tell (use visuals, comparisons)
- Use $ for pricing (StartClaw uses USD)

**Don't:**
- Use emojis anywhere (use minimalist icons instead)
- Use "No credit card required" messaging
- Explain BYOK on landing page (save for dashboard)
- Use technical jargon (VPS, Docker, SSH mentioned only as pain points)
- Over-promise or use superlatives
